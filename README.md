# Heads — предпросмотр страниц услуг

Базовые копии текущих страниц wellhead.ru для дальнейшего согласования.

| Страница | Путь GitHub Pages |
| --- | --- |
| Услуги и полный цикл брендинга | [Корень](https://yagaeo.github.io/heads-services-preview/) |
| Стратегия и позиционирование | [Стратегия и позиционирование](https://yagaeo.github.io/heads-services-preview/strategija-i-pozicionirovanie/) |
| Формирование портфеля брендов | [Формирование портфеля брендов](https://yagaeo.github.io/heads-services-preview/formirovanie-portfelja-brendov/) |
